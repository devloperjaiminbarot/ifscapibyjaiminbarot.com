# IFSC Code Lookup

A simple, fast IFSC code lookup tool for Indian banks. Pure HTML, CSS, and JavaScript — no backend, no build step.

🔗 **Live:** https://devloperjaiminbarot.github.io/ifscapibyjaiminbarot.com/

## Features
- Instant IFSC lookup
- Shows bank, branch, address, MICR, and NEFT/RTGS/IMPS/UPI support
- 100% static — hosted on GitHub Pages
- Powered by the free Razorpay IFSC API

## Files
- `index.html` — page markup
- `style.css` — styles
- `app.js` — lookup logic

## Run locally
Just open `index.html` in your browser.
