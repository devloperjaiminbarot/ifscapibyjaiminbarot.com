Frequently Asked Questions

What is an IFSC code?

The Indian Financial System Code (IFSC) is an 11-character alphanumeric code that uniquely identifies every bank branch in India. It's used for NEFT, RTGS, IMPS, and UPI transactions.

How is the IFSC code structured?

The first 4 characters identify the bank, the 5th character is always 0 (reserved for future use), and the last 6 characters identify the specific branch.

Where does this data come from?

Data is fetched in real time from the public Razorpay IFSC API, which mirrors the RBI's official IFSC registry.
